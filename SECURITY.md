# Security and responsible disclosure

KESTREL is an early prototype, not a hardened connected product. Do not expose an untested robot, debug server, default password, or development network to the public internet. Never store Wi-Fi passwords, API tokens, or private keys in this repository.

If you find a software issue that could cause unsafe motion, unintended network control, or exposure of credentials, avoid publishing exploit details while it is unresolved. Once the public repository is live, use GitHub's private vulnerability reporting if available; otherwise contact the repository owner using the private contact route in the repository profile. Include the affected commit, reproduction steps, impact, and any proposed mitigation. This project has no formal response-time guarantee or dedicated security team yet.
