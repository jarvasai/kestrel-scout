# Changelog

All notable changes to KESTREL Scout will be documented here. Version numbers remain pre-1.0 until the physical design and behavior have been built and validated.

## 0.1.0 — project starter

- Created an independent project shell and transparent early-prototype status.
- Added portable C++ behavior policy with obstacle choice, bounded burst timing, latched stop/fault handling, tilt and sensor freshness checks.
- Added native host regression tests, a repeatable test script, and GitHub Actions workflow.
- Added architecture, safety, funding, roadmap, and test documentation.
- Added CAD intake documentation; actual model files are still pending.
- Added AI-generated concept artwork clearly labeled as concept art.
- No physical robot has been assembled or validated in this release.
