# Hardware work area

This folder is organized for a transparent path from incoming CAD to reviewed printable parts and measured hardware.

- [`cad/source/`](cad/source/README.md) explains the maker's forthcoming CAD handoff and current pending-file register.
- `cad/releases/` will hold only reviewed project releases after author/source and redistribution terms are confirmed.
- Wiring and parts lists are not final until the actual CAD, controller, sensor breakouts, battery, and regulator are selected. A generic concept image is not a wiring diagram.

Before assembly, create versioned wiring/connector diagrams, exact component SKUs and datasheets, polarity/voltage/current assumptions, fuse sizing rationale, and a bench-test record. Follow the [safety guidance](../docs/SAFETY.md) and [physical test plan](../docs/TEST_PLAN.md).
